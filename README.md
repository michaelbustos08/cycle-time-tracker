# Cycle Time Tracker

A simple command line tool that tracks cycle times and calculates parts per hour across multiple machines. Data is saved to a CSV file for analysis. Built with Python as part of an IE portfolio project.

## Features
- Tracks cycle time per product
- Calculates parts per hour based on machine count
- Saves data into csv file automatically
- Input validation to prevent errors

## How To Run
```
python cycle_time.py
```

## Skills Used
- Python
- CSV Module
